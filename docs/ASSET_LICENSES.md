# Asset licences

## Project assets

All visual and audio assets in this repository are original, generated procedurally in code by this project. No textures, models, fonts, recordings or samples from third parties are included.

## Runtime dependencies

| Package | Licence | Use |
| --- | --- | --- |
| three | MIT | WebGL renderer and math |
| vite | MIT | Development server and bundler |
| typescript | Apache-2.0 | Type checking |
| vitest | MIT | Unit tests |
| @playwright/test | Apache-2.0 | Browser tests |
| eslint, typescript-eslint | MIT | Linting |

Exact versions are pinned in `package-lock.json`.

## Fonts

No webfonts are downloaded. The interface uses locally available system serif and sans-serif families (Iowan Old Style, Palatino, Georgia, Avenir, Segoe UI, Helvetica). No font files are redistributed.

## References

Links to Messenger, Journey and other works are cited for research only. No assets, code or proprietary material from those works is used. See `docs/REFERENCES.md`.

## Audio

Synthesised with oscillators, filters and generated noise buffers. No recordings, therefore no sample licences or attribution obligations.
