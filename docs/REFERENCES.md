## Originality commitments

- Island shape, landmark silhouettes, coastline and paths are original and defined in `src/config/world.ts` and `src/world/terrain.ts`.
- The traveller is built from original procedural geometry: oversized coat, scarf, small head. No marketplace humanoid.
- Ocean, sky and atmosphere shaders are written for this project.
- All audio is synthesised at runtime with the Web Audio API.
- No reference screenshots, recordings, models, textures or source code are committed.

Direct gameplay study of Messenger was not available during this build (no reliable interactive access). Camera decisions are therefore based on public descriptions, still images and documented framing principles, and are marked as proposed rather than observed. See `docs/CAMERA_DESIGN.md`.
