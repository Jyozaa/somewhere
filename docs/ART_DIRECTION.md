# Art direction

**A living painting at the edge of the ocean.**

Painterly, handmade, nostalgic. Daylight, golden hour and blue hour, never permanently gloomy. The island should look composed by a person, not scattered by noise.

| Muted sunset rose | `#BD8B7E` |
| Twilight blue | `#17283D` |
| Atmospheric slate | `#34465D` |
| Warm lantern amber | `#F2CF92` |

Grass sits around `#8D9F78`, rock `#7C817D`, timber `#8B6F52`. Warm light always plays against cool shadow.

## Rules

- Simplified geometry with irregular, handcrafted silhouettes.
- Vertex-colour variation instead of flat untextured planes.
- Soft shadows, restrained fog, atmospheric perspective.
- Ocean is art-directed: depth-tinted shallows, animated shore foam, sun glitter, horizon haze.
- Vegetation sways under one shared wind system, with per-instance phase variation.
- Character: oversized coat, scarf, small head, rounded proportions, readable at 12% screen height.
- Echoes: translucent sea-glass teal, soft, not horror-film ghosts.
- Post-processing: CSS vignette and fine grain only. No bloom, no depth of field, no heavy grading.

## Avoid

Default Three.js materials as final surfaces, primitive scatter, neon, glassmorphism UI, oversized cards, saturation overload, noisy terrain, obvious procedural grid patterns, marketplace-style assets.

## Review standard

Judge browser screenshots, not source code. A screenshot at 1440×900 with the character on the main path must read as a coherent illustrated place before any feature is called finished.
